# Design Notes: Cannabis Leaf Icon Variants (agy)

### v1 (Classic 7-Blade Palmate Fan)
- What it is: A seven-blade fan leaf composed of slender, smooth lanceolate leaflets radiating from a common hub, anchored by a separate rounded stem below.
- Recognition cues: Seven palmate leaflets with a steep length gradient, slender aspect ratio with gently rounded pointed tips, and outermost leaflets spreading wide past the horizontal axis (-96° / +96°).

### v2 (Soft-Serrated 5-Blade Leaf)
- What it is: A five-blade fan leaf where each leaflet features soft, rounded saw-tooth scalloped margins that translate cannabis serrations into the calm Poop Schedule curve language.
- Recognition cues: Forward-raked scalloped serrations along every leaflet edge, a prominent central spear, wide horizontal lateral reach (±82°), and a distinct floating petiole.

### v3 (Articulated 7-Blade Leaf)
- What it is: A seven-blade fan leaf combining dense palmate geometry with dual-tiered soft scalloped notches along each blade's shoulders.
- Recognition cues: Seven distinct palmate blades with articulated serration notches, downward-dipping lateral blades, and an acuminate tapered silhouette that reads clearly even in single-color monochrome.
